# Vendored assets

Served locally; no CDN is used at runtime. All are MIT licensed.

| File | Source | Version |
|---|---|---|
| `css/bootstrap.min.css` | https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css | 5.3.8 |
| `js/bootstrap.bundle.min.js` (with Popper, for dropdowns and the collapsing menu) | https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js | 5.3.8 |
| `js/htmx.min.js` | https://cdn.jsdelivr.net/npm/htmx.org@2.0.4/dist/htmx.min.js | 2.0.4 |

Bootstrap 5.3.8 is the latest stable 5.3 release. Bootstrap 6 is still an alpha. The two
Bootstrap files were checked byte for byte against the SHA-256 hashes jsDelivr publishes
for that release (`data.jsdelivr.com/v1/package/npm/bootstrap@5.3.8`).

`js/theme.js` and `css/app.css` are CastTrail's own.
